# Paper assets

Placeholder for camera-ready TeX tables, figure captions, and bib entries.

Until a curated slice is copied here, use the index in [`../docs/tables/README.md`](../docs/tables/README.md).

Suggested contents for a public release:

- `tab_*.tex` — main and appendix tables
- `paragraph_*.tex` — short results paragraphs
- `figures/` — only small, license-clear illustrative images (large PNG grids stay out of git)
